# Проверки TikoOS v0.3

## Выполнено на компьютере

```sh
bash scripts/test_native.sh
python3 scripts/build_native.py
```

- 331 assertions: общий UTF-8, клавиатура, настройки, пути, прежние quadrature/USB bounds.
- 557 assertions: политика нативного WebUI, строгий URL decode, размер/тип upload,
  наличие русских и математических glyphs во всех трёх нативных шрифтах.
- 7 групп сценариев **реального `target_input.c` базы**, собранного на host со
  stubs GPIO/часов: обычный click, click сразу после вращения, shaft jostle,
  reverse, sensitivity, invalid AB transitions, Back. События наблюдаются через
  тот же publish path, который использует драйвер. Это не тест физического энкодера.
- ASan + UBSan и `-Wall -Wextra -Werror` для host suites.
- Настоящая ESP32-S3 сборка, проверка app-size и ESP image checksum/hash.
- SDK checkout после сборки остаётся без tracked changes.

Это **888 assertions + 7 групп input-сценариев**, не 895 аппаратных тестов.
Отчёты находятся в `dist/`. HTML/JS дополнительно проверяется синтаксически;
HTTP/TinyUSB на реальном устройстве в этой сессии не запускались.

## На устройстве: все пункты ниже Unverified

1. **Перед установкой**: резервная копия SD/Launcher, сверка Plus-ревизии и GPIO,
   проверка свободного app-раздела по размеру BUILD.md. Не заменять таблицу разделов
   и bootloader файлом SDK. Проверить возможность отката.
2. **Старт**: питание от USB и аккумулятора; без SD загрузка Desktop/TikoOS
   продолжается. App descriptor — TikoOS 0.3.0. Back возвращает Desktop, повторный
   вход запускает TikoOS. Нет циклических reset/watchdog/brownout.
3. **Дисплей**: framebuffer 128×64 масштабируется и центрируется на 320×170,
   геометрия/цвета/поля корректны после старой прошивки и холодного запуска.
   GPIO40 не используется для LCD reset. Проверить backlight/screen timeout.
4. **Колёсико**: 100 шагов медленно в обе стороны и быстрое вращение; затем
   короткий click непосредственно после последнего шага. Меню открывается один раз
   с первого нажатия. Нажимать с боковым усилием на вал: не должно менять выбор.
   Проверить held+rotate Left/Right, long press и GPIO6 Back, сон/первое действие.
5. **Настройки ввода**: reverse, sensitivity 1–4, перезагрузка/повторный вход;
   сравнить фактические detents с обработанными шагами. В Encoder diagnostics
   записать Transitions/Invalid/Steps/AB; при механических сбоях исследовать контакты.
   Сравнить задержку с v0.2, не считать её измеренной по результату host tests.
6. **Notes/Formulas**: все демонстрационные файлы, новые категории, русский текст,
   обе азбуки с Ё/ё, математика, неизвестный emoji/replacement. Три размера шрифта,
   пустой TXT, CRLF/LF, очень длинная строка, испорченный UTF-8.
7. **Длинные документы**: TXT >2 MB, номера строк на границах 768 bytes. Листать
   вперёд/назад без пропущенных букв, закрыть, перезагрузить, проверить bookmark.
   Heap не должен расти пропорционально всему файлу. 130 файлов в папке: страницы
   по 64 дают доступ к последним файлам, а не скрывают их.
8. **Создание**: имя/текст RU/EN/символы, пробел, перенос строки, backspace одной
   кириллической буквы, Clear/OK/Cancel. Лимит 8192 bytes, одноимённый файл,
   недопустимые пути/имена, заполненная/отсутствующая SD. Ошибка видна; исходный
   файл не меняется. Прерванная запись может оставить только скрытый временный файл.
9. **Избранное**: добавить/убрать, 24 записи, перезапуск, удалённый документ:
   подтвердить удаление ссылки. Проверить read-only import старого NVS списка
   и AP-пароля/позиции v0.2; не считать разбиение строк прежнего UI идентичным.
10. **Files**: открывается настоящий Archive; папки/размеры/просмотр TXT/удаление
    работают по интерфейсу базы. Чужие документы не исчезают автоматически.
    Проверить состояния SD после возврата в TikoOS.
11. **Wi-Fi AP**: TikoOS / Tigran123456! по умолчанию. Web login tiko. Проверить
    смену пароля, повторный вход, отсутствие HTML-файла на карте: WebUI встроен.
12. **STA**: scan/cancel, SSID вручную, пароль с `!`, open network, неверный пароль,
    роутер недоступен, успешный My network IP. Подключение сохраняется между
    приложениями, после перезагрузки восстанавливается при наличии SD credentials.
    Телефон должен быть в той же LAN; проверить client isolation отдельно.
13. **HTTP**: неверный login → 401; POST без/с неверным CSRF → 403; encoded traversal,
    double encoding, NUL, control chars, backslash, trailing dots и слишком длинные
    пути отклоняются. Запись вне /TikoOS невозможна. Delete требует confirm=yes
    и действует только на файл. Upload .bin/>2 MiB/существующего имени отклоняется.
    Тестировать в AP и STA, включая обрыв загрузки и заполненный носитель.
14. **Отзывчивость WebUI**: во время большого upload/view вращать и нажимать Back.
    Проверить, что отдельная HTTP-задача не блокирует Input/GUI на всё время
    передачи. Замерить конкуренцию SD/TFT по общей SPI, heap после 20 циклов AP/STA.
15. **Bluetooth**: настройки/включение/пара с телефоном штатной базой. Переключения
    Wi-Fi ↔ BLE, восстановление состояния, повторное сопряжение. Отсутствие reboot
    при BT init и переключении радио. Проверить только свои устройства.
16. **USB Storage**: выйти в Desktop, включить штатный режим, увидеть всю SD на ПК.
    Скопировать TXT и бинарный файл в обе стороны и сравнить SHA-256. Во время
    передачи локальная FAT должна быть размонтирована. Eject на ПК, выход из режима,
    повторное монтирование/открытие документов, повторное включение MSC. Проверить
    восстановление Serial/JTAG/ROM download и поведение при потере кабеля.
17. **Tools**: Calculator 2+3, 5-8, 1.5*2, 7/2, 1/0, C/backspace/overflow. Native
    Clock start/pause/resume/reset, переходы между приложениями, изменение календарных
    часов не меняет elapsed stopwatch. После reboot секундомер сбрасывается.
18. **Settings**: штатные Interface/Notification/About, яркость и timeout, настройки
    энкодера/шрифта, Reset reader/encoder с подтверждением. Сброс не трогает Notes,
    Favorites, позиции и файлы других прошивок. На ошибке SD проверить сообщения.
19. **Длительный прогон**: час чтения и радио/USB переключений; heap/PSRAM, температура,
    ток, watchdog и целостность FAT. Power/battery telemetry должна соответствовать
    измерениям; не считать наличие I2C ACK доказательством исправности всего питания.
20. **Launcher/recovery**: возврат в Launcher, BOOT/GPIO0 ROM recovery без записи
    flash, затем только официальный способ восстановления при необходимости.
    Не использовать erase_flash и merged factory image для проверки этого app.
