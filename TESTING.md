# Проверки TikoOS v0.2

## Выполнено в облаке

```sh
c++ -std=c++17 -Wall -Wextra -Werror -fsanitize=address,undefined \
  tests/core_test.cpp -o /tmp/tiko-tests
/tmp/tiko-tests
```

331 assertions: русская азбука включая Ё/ё, корректный/некорректный UTF-8,
path sandbox, wrap навигации, квадратичные переходы/дребезг/invalid transitions,
бинарная сериализация настроек и отклонение повреждённых записей, debounce кнопок,
все пять раскладок, Unicode backspace, лимиты ввода и USB sector bounds.
Сборка PlatformIO и esptool image validation — см. BUILD.md.
Это host unit tests; они не заменяют прогон HTTP и периферии на ESP32.

## На плате: всё ниже Unverified

Перед установкой сделайте бэкап SD/Launcher, сверку hardware pins и app partition.
Не проводите тесты удаления на единственном экземпляре важных файлов.

1. **Launcher**: убедиться ESP32-S3, app-image fits выбранный раздел; сохранить
   bootloader/Launcher. Установить app, запустить; проверить возврат в Launcher.
2. **Старт без карты**: видны TikoOS, Home и SD `--`; Notes не вызывает reset.
   Проверить boot как от USB, так и от аккумулятора, не менять charger settings.
3. **Дисплей**: изображение 320×170, без смещения/обрезки и неверных цветов;
   яркость переключается, мерцания при переходах нет, анимация маркера отключается, после timeout первое действие и будит экран, и выполняется один раз. Сверить power pin и ток потребления.
4. **Ввод**: 100 медленных щелчков в каждую сторону, затем быстрое вращение;
   сравнить обработанные шаги с механическими detents. В Diagnostics контролировать
   Transitions, Invalid, Steps, Direction; при пропусках изучить разводку/контакты,
   а не увеличивать слепую фильтрацию. Проверить sensitivity 1–4 и reverse.
5. **Кнопки**: короткий click один раз, удержание один Back без повторного click,
   отдельный GPIO6 Back. GPIO0 при загрузке переводит в boot mode: это ожидаемо.
6. **SD**: пакет в корне; физически извлекать карту только при выключенном устройстве.
   Проверить SD capacity в Device Info, открыть TXT, вложенную папку и не-TXT.
   Папки >128 записей дают предупреждение. Чужие файлы должны оставаться целыми.
7. **Кириллица**: открыть `TikoOS/assets/Unicode.txt`; сверить обе азбуки и Ё/ё,
   математику. Дописать unsupported emoji: должен быть replacement glyph, не crash.
   Тестировать пустой TXT, CRLF и LF, длинную строку, битый UTF-8.
8. **Длинный документ**: создать TXT >2 MB с нумерованными русскими строками,
   проверить переходы через 768-byte boundaries вперёд/назад без потери букв,
   все три шрифта и переносы. Закрыть, перезапустить, открыть — та же страница/строка.
   Измерить heap при листании: он не должен расти пропорционально размеру файла.
9. **Формулы**: четыре предмета читаются с карты; добавить свой предмет/тему,
   выйти и заново открыть каталог: новые файлы появляются без пересборки.
10. **Избранное**: добавить, открыть из Home, убрать, повторно добавить, перезагрузить;
    удалить файл через Files — ссылка удаляется. Удалить вручную на выключенной SD —
    ссылка `[нет]`, click предлагает убрать. Проверить ограничение 24 документов.
11. **Удаление**: TXT — меню читателя; другой файл — click/hold в Files. «Нет»
    сохраняет файл. «Да» удаляет только выбранный файл в `/TikoOS`. Файлы других
    прошивок за пределами `/TikoOS` не удаляются; каталоги не удаляются.
12. **WebUI**: Home → Wi-Fi Transfer. Подключить телефон к WPA2 AP `TikoOS`,
    открыть показанный IP (обычно 192.168.4.1), login tiko + показанный пароль.
    Проверить список, просмотр, mkdir, upload TXT, затем открытие загруженного TXT
    на устройстве. Проверить свободное место; переполненная SD должна дать ошибку.
13. **Web security**: неверный login → 401; POST без/с неверным `X-Tiko-CSRF` → 403.
    Через browser devtools взять токен из страницы для разрешённых тестов.
    Отправить пути `/TikoOS/../other`, encoded traversal, backslash, control chars,
    слишком длинное имя; все должны отклоняться без записи за пределами sandbox.
    Запрос delete без `confirm=yes` не удаляет. На WebUI удаление требует confirm.
    Загрузка существующего имени, не-TXT и >2 MiB отклоняется; исходник не меняется.
    В HTML-именах `<`, `>`, кавычки не должны исполнять script.
14. **Потеря связи**: оборвать upload, проверить исходные файлы и временный файл;
    выйти из Transfer — AP исчезает. Заново зайти — сохранённый пароль остаётся; поменять пароль через клавиатуру
    и проверить, что новый применяется, а старый больше не принимается.
    Замерить задержки UI во время upload/view (известное ограничение WebServer).
15. **Calculator**: `2+3=5`, `5-8=-3`, `1.5*2=3`, `7/2=3.5`, `1/0` показывает
    ошибку; C, <, повторное =, длинное число, переполнение — без crash/NaN.
16. **Stopwatch**: start/pause/resume/reset; время идёт вне экрана, пауза сохраняется.
    Сравнить с внешними часами 10 минут. Питание выключает stopwatch — ожидаемо.
17. **Settings**: каждую настройку поменять, перезапустить, проверить сохранение;
    Reset Settings подтверждается отдельно, не трогает SD/избранное.
18. **Диагностика**: CPU/heap/PSRAM/flash соответствуют плате; battery Unknown,
    адрес ACK не выдаётся за тест PN532. CC1101/nRF24 остаются not probed,
    RF/IR не передаются. Нет неожиданных LEDs/потребления радио.
19. **Длительный прогон**: час чтения/навигации и 20 циклов Wi-Fi; следить за heap,
    watchdog/reset, температурой и питанием, затем проверить целостность SD.
20. **Recovery**: проверить возврат в Launcher GPIO6 и USB ROM download GPIO0,
    сначала без записи flash. Не выполнять erase_flash и не шить factory image
    поверх Launcher для этого теста.

## Регрессии и новые функции v0.2 (на оборудовании не выполнены)

21. **Лаг и двойной click**: прокрутить Home, Notes, Files по 100 шагов. После
    каждого короткого click приложение открывается один раз с первого нажатия.
    Повторить сразу после вращения и после screen timeout. Убедиться, что вращение
    перед click не применяется уже к дочернему экрану. Яркость при переходе постоянна.
    Сравнить задержку с предыдущей версией; записать измерения, не считать fps=60
    доказанным только по программному лимиту кадров. Проверить цвета dirty-row blits.
22. **Queue**: диагностический экран показывает Queue drops. Несколько коротких
    нажатий во время перерисовки сохраняются; при долгом Web upload проверить лимит
    очереди, задержку исполнения Back и отсутствие повторного открытия приложения.
23. **Раскладки**: пять страниц по 36 видимых glyphs; проверить все символы, особенно
    `!`, цифры, Ё/ё, обратный слеш, кавычки и кириллицу. Проверить Space, Clear,
    Enter, Unicode backspace, OK/Cancel, маскирование и ограничения длины.
24. **Wi-Fi AP**: начальный пароль Tigran123456!, Web login tiko. Изменить пароль,
    перезапустить устройство, проверить сохранение и отказ со старым паролем.
25. **My network**: поиск сетей не блокирует клавиатуру/Back; подключить роутер 2.4 GHz,
    ввести пароль с `!`, открыть адрес устройства с другого клиента LAN. Перезапустить,
    зайти в My network без повторного ввода. Проверить неверный пароль, отсутствие AP,
    отключение роутера и восстановление, повторные входы в AP/My network без утечки heap.
    Проверить HTTP 401/403/CSRF и path sandbox в обоих режимах.
26. **Notes create**: имя и текст на русском, пробелы/новые строки, >768 байт;
    сохранить, открыть, проверить UTF-8 на ПК. Повтор имени не перезаписывает файл.
    `../`, `/`, `:`, `*`, hidden name и trailing dot/space отклоняются. Cancel/Back
    не создаёт файл. Проверить пустой текст, лимит 8192 байта, заполненную SD.
27. **USB MSC**: сначала на тестовой карте с резервной копией. До выбора режима
    диск не доступен. После подтверждения появляется полная SD, CDC остаётся виден.
    Скопировать TXT и бинарный файл в обе стороны, сравнить SHA-256 на ПК и SD.
    Проверить большие файлы и неполные sector writes на Windows/Linux/macOS, если доступны.
    Экран статичен, Wi-Fi отсутствует, локальные операции недоступны. Eject должен
    перезапустить плату; после reboot новые документы читаются без повреждений FAT.
    Наличие USB-кабеля без запущенного MSC не должно вызывать самопроизвольный restart.
28. **USB recovery**: после смены USB Serial/JTAG на TinyUSB OTG проверить новый CDC port
    и ROM download через GPIO0. Проверить возврат к Launcher после штатного Eject.
    Firmware app не должен изменять bootloader, таблицу разделов или файлы Launcher.
