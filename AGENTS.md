# Правила работы с проектом

При каждом изменении проекта обновляйте `aireadme.md` в том же коммите:
добавляйте сверху запись с датой, описанием изменений, выполненными проверками
и оставшимися ограничениями. Не записывайте непроведённые проверки как успешные.
Сохраняйте существующую историю журнала. Это постоянное требование пользователя.
