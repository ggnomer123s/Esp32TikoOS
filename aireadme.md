# Журнал изменений TikoOS

Здесь фиксируются изменения проекта: что сделано, какие проверки выполнены
и какие ограничения остались. Новые записи добавляются сверху, под этим описанием.

## 2026-11-14 — v0.2: ввод, USB, Wi-Fi и создание заметок

- Удалён PWM fade при открытии экранов, вызывавший видимое мерцание.
- Первое действие после screen timeout теперь сразу выполняется, а не теряется
  на пробуждение. Движение из очереди применяется до click к исходному экрану.
- Debounce кнопок вынесен в отдельную FreeRTOS-задачу; введена очередь событий,
  диагностируется её переполнение. ISR quadrature сохранён без ускорения.
- Renderer передаёт только изменившиеся полосы строк RGB565; glyph рисуется
  горизонтальными отрезками. Кадры ограничены 16 ms, накопленные события объединяются.
  В render больше нет SD.exists для каждого избранного и сканирования FAT free-space.
- Wi-Fi Transfer получил AP и My network, асинхронный поиск/подключение,
  сохранение SSID/пароля в NVS, ввод SSID вручную, обработку потери соединения.
- Начальный пароль AP и WebUI — `Tigran123456!` по требованию пользователя;
  пользовательский пароль меняется клавиатурой и сохраняется. Логин WebUI `tiko`.
- Добавлена EN/RU/символьная клавиатура: пять раскладок по 36 символов, пробел,
  перевод строки/очистка, Unicode backspace, OK/Cancel, маскированные пароли.
- Notes: создание TXT в текущей папке, до 8192 байт UTF-8, проверка имени,
  временный файл и rename без перезаписи существующего документа.
- USB Transfer: TinyUSB CDC + MSC, вся microSD как USB-диск; локальные SD/TFT и
  сеть не используются при экспорте. Callback проверяет границы, сериализует raw I/O.
  Host Eject запускает перезагрузку, чтобы не использовать старый FAT-кэш.
- Обновлены firmware.bin, microsd.zip, отчёты, README, TESTING.md и hardware notes;
  добавлены исходники v0.2 ZIP и воспроизводимый скрипт упаковки.
- Проверки: успешная ESP32-S3 сборка, 331 host assertion с ASan/UBSan,
  проверка ESP image checksum/hash и целостности архивов. Подробности — BUILD.md.
- На физической плате не проверены скорость интерфейса, Wi-Fi и USB/Eject.
  WebServer остаётся синхронным; большая передача может задерживать UI,
  но ввод собирается отдельной задачей (очередь конечна). USB отдаёт всю карту;
  обязательны безопасное извлечение и последующий restart. Работа с конкретной
  Plus-ревизией и Launcher по-прежнему требует аппаратного чек-листа.

- Пакет карты переименован из `dist/TikoOS-v0.1-sd.zip` в `dist/microsd.zip`;
  содержимое архива не изменено. Ссылки в README обновлены.
- Добавлены краткие указания по распаковке пакета и установке через Launcher.
- Создан этот журнал и ссылка на него в README.
- В `AGENTS.md` закреплено требование обновлять журнал при дальнейших изменениях.
- Проверки: целостность ZIP, соответствие вложенного `firmware.bin` отдельному
  бинарнику и контрольной сумме, корректность путей ссылок. Код прошивки не менялся,
  повторная сборка не требовалась.

## 2026-11-14 — Первоначальный прототип v0.1

Коммит: `fa44d7d`.

- Создан PlatformIO-проект для ESP32-S3 семейства T-Embed CC1101.
- Добавлены интерфейс, русский текст, Notes, Formulas, Favorites, Files,
  Wi-Fi Transfer, инструменты, настройки и диагностика энкодера.
- Подготовлены демонстрационные файлы SD, app-image, инструкции установки
  и восстановления, аппаратный чек-лист и сценарии облачной сборки.
- Сборка прошла; 98 host-проверок выполнены. Подробности — `BUILD.md`.
- Проект отправлен в GitHub, ветка `main`.
- Работа на физической плате и совместимость конкретной Plus-ревизии не проверены;
  ограничения перечислены в README и TESTING.md.
